
# System Design Lab — Roadmap

## Project Goal

Build a hands-on Order Management API to understand
backend development, REST APIs, distributed systems,
scalability, reliability, and API testing.

Repository: https://github.com/devnutan/system-design-lab

## Technology Stack

- Node.js
- TypeScript
- Express
- PostgreSQL (planned)
- Redis (planned)
- NGINX (planned)
- Docker (planned)
- Playwright API Testing (planned)
- GitHub Actions (planned)
